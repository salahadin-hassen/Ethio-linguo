# Bundled fonts

Both families are licensed under the SIL Open Font License 1.1 (OFL), which permits bundling in applications.

| Family | Use | Source |
|---|---|---|
| Nunito (Regular–Black, Latin subset) | Primary UI typeface (English, Afaan Oromo) | Google Fonts via Fontsource |
| Noto Sans Ethiopic (Regular–ExtraBold) | Ethiopic script (Amharic, future Tigrinya) — used as font fallback | Google Noto project |

Fonts are bundled so the UI never depends on network font loading or device-installed Ethiopic fonts.
