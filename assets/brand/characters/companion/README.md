Rive CLI project for the Companion rig (artboard `Companion`, state machine `CompanionCharacter`).

- `companion.rml`: the rig source (hand-authored RML, verified with `rive . --verify`).
- `companion.riv`: produced by `rive . --publish` (needs `rive login`). The app loads it automatically when it is present.

Contract: docs/CHARACTER_RIG_SPEC.md and lib/features/mascot/rig/rig_contract.dart.
